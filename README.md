## 🚀 Deployment

### Local Development
Simply open `index.html` in your browser.

### Production Deployment
1. Push to GitHub (or any Git hosting)
2. Deploy via:
   - **GitHub Pages** — Free hosting, automatic deploys
   - **Netlify** — Drag & drop or Git integration
   - **Vercel** — Optimized for web projects
   - **Traditional Hosting** — FTP/SFTP upload
