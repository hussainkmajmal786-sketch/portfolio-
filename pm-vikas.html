Day 01
Resistors, Ohm's Law, KCL & KVL
Dr. Anand — HOD ECE, IIIT Kottayam
Network Theory Resistors Ohm's Law Kirchhoff
+
Course Overview

Core areas covered: Network Theory, Circuits & Networks, Basic Electronics, and Rectification. Real-world example: understanding the hardware inside a heart rate monitor.

Rectification & Inside the Charger

Studied the internal components of a charger — full wave rectifier passing through a bridge rectifier to produce half-wave output, then filtered through RC, RLC, or LC filters (R = Resistance, L = Inductance, C = Capacitor).

Key Insight
RC filter is the most efficient. Output starts as fluctuating DC, converted by rectifier to actual DC. A potential/voltage divider (e.g., 12V → 5V) works using resistances.
Resistors

A resistor doesn't have polarity — it's a two-terminal device measured in Ohms. Modern electronics uses surface-mount resistors on boards.

Resistor Color Code: B B R O Y G B V G W — S G

B B R O Y G B V G W
Series & Parallel
Series: Current is same, voltage is different. R_total = R₁ + R₂ + ...
Parallel: Voltage is same, current is different. 1/R_total = 1/R₁ + 1/R₂ + ...
Ohm's Law
⚡ Formula
V = R × I   (at constant temperature)

Ammeter → connected in Series
Voltmeter → connected in Parallel
Kirchhoff's Laws
KCL — Kirchhoff's Current Law
Total current entering a node = Total current leaving the node.
KVL — Kirchhoff's Voltage Law
Total voltage rise across a closed loop = Total voltage drop.
Voltage & Current Divider Rules
Voltage Divider
V(R₁) = R₁ / (R₁ + R₂) × V_total
Example: 12V → 5V using two resistors
Current Divider
Works inversely — verify theoretically and practically using simulators.
Advanced Analysis (Afternoon)

Topics covered post lunch break (1:00 PM): Nodal Analysis, Super Mesh Analysis, Super Node Analysis, Superposition Principle, and various Network Theorems.

  1. Use online simulators or virtual labs to verify circuit behavior
  2. Practice resistor color code identification
  3. Calculate effective resistance in series & parallel circuits with currents
  4. Solve problems on Ohm's Law, KCL, KVL, CDR, VDR (try with ChatGPT and simulators)

Active & Passive Devices
Key Distinction
Passive: Cannot amplify — Resistor (resists electron flow, Ω), Capacitor (stores electric field, blocks DC, passes AC — Farad), Inductor (stores magnetic field, blocks AC, passes DC — Henry).

Active: Can amplify/process signals — Transistors, Diodes. Classified into tube devices and semiconductor devices.

Day 07
Digital Electronics — Logic Gates & Boolean Algebra
Dr. Vineeth — 22/05/2026 (continued)
Boolean Logic Gates Number Systems K-Map
+
Analog vs Digital
Key Difference
Analog: Sinusoidal signals with infinite possible values — very difficult to process.
Digital: Only two discrete values (0 and 1). Easier to process, noise-immune, modular designs possible.
Advantages of Digital Systems

Noise immunity · Power of abstraction · Modular designs · Faster design completion · Software tools ease · Programmability

Logic Gates — The Building Blocks
GateCircuitRule
ANDSwitches in seriesOutput 1 only if ALL inputs are 1
ORSwitches in parallelOutput 1 if ANY input is 1
NOTInverterOutput is the inverse of input

Other gates: NAND, NOR, XOR, XNOR. Digital Trainer Kit uses ICs in Dual In-Line Package (DIP).

Number Systems

Covered conversions between Decimal, Binary, Hexadecimal, and Octal. Also: 1's complement and 2's complement for signed numbers.

Example: Hex 2A → Decimal
2A → Binary: 0010 1010
Binary → Decimal: 0+0+32+0+8+0+2+0 = 42
Boolean Algebra — Core Laws
LawAND (·)OR (+)
IdentityA · 1 = AA + 0 = A
NullA · 0 = 0A + 1 = 1
IdempotentA · A = AA + A = A
ComplementA · A' = 0A + A' = 1
De Morgan's Theorems
(A + B)' = A' · B'
(A · B)' = A' + B'
Other Laws
Commutative: A+B = B+A, A·B = B·A
Associative: A+(B+C) = (A+B)+C
Distributive: A·(B+C) = A·B + A·C
Absorption: A+(A·B) = A
Karnaugh Map (K-Map)

A graphical method to simplify Boolean expressions. Uses Gray code ordering so adjacent cells differ by only one variable. Group adjacent 1s (for SOP) or 0s (for POS) to eliminate variables.

K-Map Rules
Groups must be 1, 2, 4, or 8 cells · Rectangular shapes only · Largest possible groups · Edge cells can wrap around · Diagonal cells are NOT adjacent

Don't Care (X): Incomplete specified functions — treat as 0 or 1 to make larger groups, reducing gate count.

Network Analysis & Synthesis

Analysis: Given a circuit → find current, voltage, power (KCL, KVL, Mesh, Nodal, Superposition, Thevenin, Norton).
Synthesis: Given a desired function → design the circuit using AND, OR, NOT gates (Sum of Products form).

Half Adder
Equations

Carry: C = A · B  (AND)

Equations

Built using two half adders + one OR gate. Essential for multi-bit arithmetic.

Half & Full Subtractor
Half Subtractor
Difference: D = A ⊕ B
Borrow:   Bₒᵤₜ = A' · B
Full Subtractor
Difference: D = A ⊕ B ⊕ Bᵢₙ
Borrow:   Bₒᵤₜ = A'B + A'Bᵢₙ + BBᵢₙ
Multiplexer (MUX) & Demultiplexer (DEMUX)
MUX — Data Selector

Many inputs → one output. Uses selection lines. 4:1 MUX: Y = S₁'S₀'I₀ + S₁'S₀I₁ + S₁S₀'I₂ + S₁S₀I₃

DEMUX — Data Distributor

One input → many outputs. 1:4 DEMUX distributes input D to one of Y₀–Y₃ based on selection.

FeatureMUXDEMUX
FunctionSelects one inputSelects one output
Data FlowMany → OneOne → Many
UseData selection, TDMData distribution, memory addressing
Encoders & Decoders
Encoder (8:3)

2ⁿ inputs → n outputs. Converts active input line to binary code. Priority encoder handles multiple active inputs.

Decoder (3:8)

n inputs → 2ⁿ outputs. Activates exactly one output based on binary input. Used in memory addressing & 7-segment displays.

Day 09
Sequential Logic — Flip-Flops & State Machines
Dr. Vineeth — Continued
Flip-Flops Counters State Diagrams Sequential
+
Combinational vs Sequential
Key Difference
Combinational: Output depends only on present inputs.
Sequential: Output depends on present inputs + previous states (memory).
Types of Sequential Circuits
Synchronous

Uses clock signal. State changes at clock pulses. Easier to design. Examples: counters, registers, digital clocks.

Asynchronous

No clock. State changes immediately on input change. Faster but complex. Examples: ripple counters.

Flip-Flops — Memory Elements
TypeInputsBehavior
SRS, RSet/Reset. S=R=1 is invalid.
JKJ, KImproved SR. J=K=1 → Toggle.
DDStores input directly. D=0→Q=0, D=1→Q=1.
TTToggle. T=0→No change, T=1→Toggle.
Design Steps for Sequential Circuits
  1. Understand the problem — identify inputs, outputs, and states
  2. Draw the state diagram (circles = states, arrows = transitions)
  3. Create the state table (present state → next state)
  4. Perform state assignment (binary codes to states)
  5. Choose flip-flop type (D is simplest)
  6. Derive flip-flop input equations using K-Maps
  7. Draw the final logic circuit diagram
State Assignment Methods

Binary: States in binary order · Gray Code: One bit change between adjacent states · One-Hot: Each state uses one flip-flop

Design Tip
State reduction minimizes hardware by combining equivalent states. This reduces flip-flop count and simplifies the overall design.

What is an Embedded System?

An embedded system is a dedicated computer built into a larger device to do one specific job — washing machines, microwaves, cars, and of course IoT devices. Unlike a general-purpose PC, it's optimised for a fixed task with tight constraints on power, cost, and size.

Key Traits
Real-time response · Low power · Reliable & long-running · Resource-constrained (limited memory & CPU) · Often runs without an operating system (bare-metal).
Microprocessor vs Microcontroller
FeatureMicroprocessorMicrocontroller
Memory / I/OExternal (separate chips)On-chip (all-in-one)
CostHigherLower
UsePCs, heavy computingDedicated control tasks
ExampleIntel Core, PentiumATmega328P, PIC, ESP32
Inside the Microcontroller

A microcontroller packs the whole computer onto a single chip:

CPU

The brain — fetches, decodes, and executes instructions.

Memory

Flash (program), SRAM (data), EEPROM (non-volatile storage).

I/O Ports

Digital & analog pins to talk to sensors and actuators.

Timers / ADC

Timers/counters, ADC for analog reads, and communication units.

The ATmega328P (Arduino Uno's Brain)
Spec Snapshot
8-bit AVR · 16 MHz · 32 KB Flash · 2 KB SRAM · 1 KB EEPROM · 14 digital I/O (6 PWM) · 6 analog inputs · UART, SPI, I²C.

Memory Architecture
Von Neumann vs Harvard
Von Neumann: Program & data share one memory + one bus.
Harvard: Separate memory & buses for program and data — faster, used by AVR (ATmega328P).

Each pin can be configured as input (read a sensor/button) or output (drive an LED/relay). Covered pull-up / pull-down resistors to keep floating inputs at a defined logic level, and the idea of registers (DDR, PORT, PIN) behind Arduino's friendly functions.

The OSI Reference Model

Walked through all 7 layers and how data moves down the stack on the sender side and back up on the receiver side. Each layer adds its own header (encapsulation).

#LayerRole
7ApplicationUser-facing services (HTTP, MQTT)
6PresentationEncryption, encoding, compression
5SessionOpens / maintains / closes connections
4TransportEnd-to-end delivery (TCP, UDP)
3NetworkRouting & addressing (IP)
2Data LinkMAC addressing, framing
1PhysicalBits over the wire / radio
TCP/IP & Addressing
Key Concepts
IP Address: Logical address of a device on a network (IPv4 = 32-bit, IPv6 = 128-bit).
MAC Address: Physical hardware address burned into the NIC.
Ports: Identify a specific service (HTTP=80, HTTPS=443, MQTT=1883).
DNS: Resolves human-readable names into IP addresses.
TCP vs UDP
FeatureTCPUDP
ConnectionConnection-orientedConnectionless
ReliabilityGuaranteed, orderedBest-effort
SpeedSlowerFaster
UseWeb, email, file transferStreaming, gaming, DNS
IoT Communication Protocols
MQTT

Lightweight publish / subscribe protocol over TCP. Ideal for low-bandwidth IoT devices. Uses a central broker.

HTTP / REST

Request–response over TCP. Simple but heavier than MQTT for constrained devices.

CoAP

Constrained Application Protocol — REST-like but runs over UDP for tiny devices.

WebSocket

Full-duplex channel over a single TCP connection — great for live dashboards.
